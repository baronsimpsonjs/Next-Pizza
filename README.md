# 🍕 Next Pizza

**Full-stack web app** for a modern pizza shop, built with **Next.js 14**, **Prisma ORM**, **TailwindCSS**, and **Radix UI**.  
Containerized with **Docker**, deployed via **Railway**, and powered by **CI/CD** using GitHub Actions.

---

## 🧰 Stack

| Layer         | Tech                                                                        |
| ------------- | --------------------------------------------------------------------------- |
| Framework     | [Next.js 14](https://nextjs.org/)                                           |
| Styling       | [TailwindCSS](https://tailwindcss.com/)                                     |
| UI Components | [Radix UI](https://www.radix-ui.com/) + [Lucide Icons](https://lucide.dev/) |
| State         | [Zustand](https://zustand-demo.pmnd.rs/)                                    |
| DB & ORM      | [Prisma ORM](https://www.prisma.io/) + PostgreSQL                           |
| Auth          | [bcrypt](https://www.npmjs.com/package/bcrypt)                              |
| HTTP Client   | [Axios](https://axios-http.com/)                                            |
| Utils         | clsx, class-variance-authority, react-use                                   |
| i18n          | [next-i18next](https://github.com/i18next/next-i18next)                     |
| Container     | Docker (multi-stage build)                                                  |
| Deployment    | [Railway](https://railway.app/)                                             |
| CI/CD         | GitHub Actions                                                              |
